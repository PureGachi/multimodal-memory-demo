总体结果


这些数字不等于回答正确率。
Hit@K：有标注的题中，前 K 条至少命中一处标注轮次的题目比例。
Recall@K：每题找回标注轮次的比例，再取平均；需要 A/B/C、找到 A/B，该题就是 2/3。
MRR@K：第一处证据排第 r，记 1/r；没找到记 0，再取平均。此处显示小数，不是百分比。
全部找回率：所有标注轮次都找齐的题目比例。K 按消息计，同轮两种角色可能占两条；无 clue 题不计分。
“非标注轮次”不一定无用，“命中轮次”也不保证这条消息能回答。请结合原文判断。
