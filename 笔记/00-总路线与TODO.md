> 建立日期：2026-10-01

## 一句话总目标

以 **Python + AI** 为主技术栈，用“多模态记忆竞赛 → 生产级 Agent → CAD/3D 课题”形成一条连续的项目路线，最终沉淀为能够支撑 **CAD/CAE/CAM、制造业和工业 AI 实习** 的作品与研究成果。

- 主技术栈确定为 Python + AI，不把 C++ CAD 内核开发作为近期门槛。

### 2026-10-02

- 竞赛笔记已迁移到实际开发目录 `D:\Dev\Windows\Python\26-10-Memory\笔记`。
- 第一个 Demo 定义为遵守官方契约的多模态记忆服务，而不是聊天 Agent。

## 维护规则

每次更新只做以下几类动作：

1. 新任务先判断属于哪条主线，避免重复创建；
2. 当前同时活跃的核心任务尽量不超过三个；
3. 已完成任务保留勾选，并在必要时附成果链接；
4. 方向变化写入“关键决策记录”，同时说明为什么改变；
5. 每周检查一次近期执行顺序，删除失效任务；
6. 资料型内容放入独立日期笔记，总控文档只保留结论和入口。
