# 方法、来源与复现边界

## 当前版本

v0.3.0：Python/FastAPI Add/Search 记忆服务；固定代码应以 Git 完整 Commit 为准，不能只提交会移动的 main 分支地址。确切运行配置与模型版本另外记录，不公开密钥。

每条消息保留原始有序图文；SQLite 保存证据、向量、派生描述及幂等记录，本地媒体目录保存原图。文本按 400 字符分块。关键词 BM25、文本向量及图片字节哈希通道通过 RRF 融合，再按消息数和媒体预算返回原证据。SQLite/JSON 线性检索是小型 baseline，不宣称 HNSW 或大规模生产容量。

可选图片分析输出视觉描述/可见文字；新上下文模式另外保存说话者明确提供的背景及输入来源。上下文只取同一 Add 的当前消息，以及 assistant 前紧邻的 user 消息，单条最多 4000 字符；不加载后续消息、评测问题或金标。它不能保证模型不会幻觉，也不等于实现了跨消息图片补全。

competition 配置指定 `gpt-4o-mini` 和 `text-embedding-v4`，禁用未确认的本地 OCR；模型请求不自动重试。配置模型名不证明供应商真实模型或第三方合规，须由参赛人向官方与供应商确认。平台负责最终 Answer/Eval，本项目不代替官方评分。

## 本次变更与实验限制

从仓库最初文本 demo 扩展了可配置视觉/OCR、文本 embedding API、图文评测与工作台、查询图片理解、缓存/断点、安全错误反馈、连接复用、容量保护、Docker 和离线安装包验收；v0.3.0 增加上下文图片索引、保留清理工具、发布审查和 MIT 许可。
